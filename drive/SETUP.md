# 구글 드라이브 자동 저장 연결하기 (선생님용, 약 5분)

완성된 네컷이 선생님 드라이브의 `가을네컷/2026-10-13/` 같은 날짜 폴더에 자동으로 올라갑니다.

## 1. Apps Script 만들기

1. https://script.google.com 에 사진을 받을 구글 계정으로 로그인 → **새 프로젝트**
2. 프로젝트 이름을 `가을네컷 저장`으로 바꾼다
3. 기본 코드를 모두 지우고 [Code.gs](Code.gs) 내용을 통째로 붙여넣는다
4. 맨 위의 `SECRET` 값을 나만 아는 문자열로 바꾼다 (예: `단풍-7392-은행`)
5. 저장(💾) → 위쪽 함수 목록에서 `setup` 선택 → **실행**
   - "권한 검토" → 계정 선택 → "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → 가을네컷 저장(으)로 이동** → 허용
   - 내가 만든 스크립트라서 나오는 경고예요. 드라이브에 폴더를 만들고 파일을 넣을 권한을 묻는 것입니다.
   - 실행 로그에 `저장 폴더: https://drive.google.com/...`가 나오면 성공

## 2. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
2. 실행 사용자: **나** / 액세스 권한이 있는 사용자: **모든 사용자**
3. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사

> "모든 사용자"여야 태블릿이 로그인 없이 사진을 보낼 수 있어요. 대신 비밀 코드가 맞아야만 저장됩니다.

## 3. 태블릿 연결

1. 태블릿에서 https://sdh19881111.github.io/gaeul-4cut/ 열기
2. 오른쪽 위 ⚙️ → 웹 앱 URL과 비밀 코드 입력 → **연결 테스트** → **저장**
3. 시작 화면에 "☁️ 구글 드라이브 자동 저장 켜짐"이 보이면 끝

**태블릿이 여러 대라면**: 첫 태블릿의 ⚙️에서 **다른 태블릿용 연결 링크 복사** → 그 링크를 다른 태블릿에서 한 번씩 열면 바로 연결돼요. 링크에 비밀 코드가 들어 있으니 학생들에게는 보내지 마세요.

## 참고

- 드라이브에는 JPEG(약 1MB)로 올라가요. 기기에 저장하는 파일은 PNG 원본 그대로입니다.
- 업로드에 실패하면 저장 화면에 "다시 올리기" 버튼이 나와요.
- Code.gs를 고쳤다면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영돼요 (주소는 그대로).
- 연결을 끊으려면 태블릿의 ⚙️ → **이 기기 연결 끊기**를 누르세요. 모두 막으려면 Apps Script의 SECRET을 바꾸고 새 버전으로 배포하면 됩니다.
- 사진이 기기 밖(선생님 드라이브)으로 나가게 되므로, 필요하면 학생·학부모에게 사진 수집을 안내해 주세요.
