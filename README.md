# 가을네컷 (MVP)

4컷 사진을 찍어 가을 프레임과 필터로 꾸미고 PNG로 저장하는 웹앱. 서버 없이 기기 안에서만 처리한다.

## 실행

카메라는 `https://` 또는 `localhost`에서만 켜진다. 파일을 더블클릭해서 열면 동작하지 않는다.

```bash
python -m http.server 5195
```

- http://localhost:5195 : 실제 카메라
- http://localhost:5195/?demo : 카메라 없이 움직이는 테스트 화면으로 전체 흐름 확인
- http://localhost:5195/dev/sheet.html?filter=film : 프레임 6종을 한눈에 비교 (개발용)

## 배포

이 폴더를 그대로 GitHub Pages 또는 Netlify에 올리면 된다 (빌드 과정 없음).

## 구글 드라이브 자동 저장 (선택)

완성본을 선생님 드라이브로 자동 업로드한다. Apps Script를 한 번 배포하고 태블릿마다 연결한다. → [drive/SETUP.md](drive/SETUP.md)

## 구조

| 파일 | 역할 |
| --- | --- |
| `js/app.js` | 화면 흐름 (시작 → 촬영 → 확인/재촬영 → 꾸미기 → 저장) |
| `js/camera.js` | 카메라 켜기·끄기, 가운데 4:3 자르기, 앞 카메라 좌우 반전, `?demo` |
| `js/frames.js` | 프레임 6종 (사진 칸 좌표 + 배경/장식 그리기). 프레임 추가는 여기만 수정 |
| `js/shapes.js` | 단풍잎·은행잎·도토리·코스모스 등 직접 그린 장식 |
| `js/filters.js` | 원본·필름톤·앰버·빈티지 (픽셀 직접 계산, iOS 사파리 대응) |
| `js/compose.js` | 4컷 + 프레임 + 필터 + 날짜 합성 (결과 1200px 폭 PNG) |
| `js/drive.js` | 드라이브 연결 설정(기기별 localStorage)·업로드 |
| `drive/Code.gs` | 드라이브 저장용 Apps Script (선생님 계정에 배포) |
| `js/effects.js` | 저장 화면 낙엽 효과(2초), 로고 장식 |
